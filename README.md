# currency-conversion
A simple currency converter web application that allows users to convert between different currencies using real-time exchange rate data from an API.

Technologies Used
HTML5
CSS3
JavaScript (Vanilla JS)
Exchange Rate API
Features
Convert between multiple currencies
Fetch real-time exchange rates from an API
Display conversion results instantly
Simple and responsive user interface
What I Learned

Through this project, I learned how to:

Work with APIs in JavaScript
Fetch data from external sources using asynchronous requests
Handle API responses and extract the required information
Display fetched data to users in a clear and organized way
